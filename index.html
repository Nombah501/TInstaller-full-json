Как ввести

  1. Открой TInstaller → найди поле для URL JSON-каталога.
  2. Введи одну из ссылок выше.
  3. Дождись загрузки — каталог появится на русском.

Формат: {"apps": [{title, description, category, url, mirror, ver}]} — совместим с оригиналом.
